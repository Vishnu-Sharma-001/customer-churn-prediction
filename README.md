# AI Customer Churn Prediction & Analytics Dashboard

Interactive Streamlit dashboard for predicting telecom customer churn using an Artificial Neural Network (ANN).

## Features
- **Overview**: KPIs, churn statistics, interactive Plotly charts, auto-generated insights
- **Prediction**: Enter customer details and get real-time churn probability
- **Data Explorer**: Upload CSV, filter records, download predictions

## Quick Start
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
Python · Pandas · NumPy · Scikit-learn · TensorFlow/Keras · Plotly · Streamlit
